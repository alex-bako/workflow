# T1 — Parse and format durations

Card: S2.1 — Reminder schedules (bullets: T1 durations, T2 reminder schedule,
T3 snooze). Bullet: T1. Status: accepted.

## Acceptance

- `parseDuration` returns whole seconds: `"90s"` → `90`, `"1h30m"` → `5400`, `"2d"` → `172800`.
- Units may appear once each, in the order d, h, m, s; anything else throws `RangeError`, including `""` and `"5"`.
- `formatDuration(5400)` → `"1h30m"`; zero units are omitted; `formatDuration(0)` → `"0s"`.

## Invariants

- A duration is an integer number of seconds; no fractional values.
